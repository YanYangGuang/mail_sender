# 本地邮件发送台

这是一个运行在 Windows 本机的可视化邮件工具，使用 Python、FastAPI 和 SQLite。它面向个人本地使用：收件人、模板、SMTP 配置、批量任务、任务明细和发送日志都由本机项目管理。

> SMTP 显示“已提交”只代表邮件服务器接受了提交请求，不代表邮件最终进入收件箱。

## 目录与数据位置

```text
mail_sender/
├── main.py                 # Web 服务、页面路由和业务逻辑
├── sample_data.py          # 演示收件人与模板
├── sample_data/
│   └── recipients.csv      # 可用于练习导入的 CSV 示例
├── templates/
│   └── page.html           # 页面模板
├── data/
│   └── mail_sender.db      # 本机 SQLite 数据库，首次启动时创建
├── requirements.txt        # Python 依赖
├── start.bat               # Windows 启动脚本
└── README.md
```

数据库默认保存在 `data/mail_sender.db`。数据库和 SMTP 密码都属于本机数据，备份或迁移项目时请妥善保护。

## 一、运行环境

- Windows 10 或 Windows 11。
- Python 3.11.5 或更新版本。
- 首次安装依赖时需要联网，以便 pip 下载 Python 软件包。
- 建议将项目放在普通用户有读写权限的目录中。

检查 Python：打开命令提示符或 PowerShell，运行：

```text
python --version
```

应显示 `Python 3.11.5` 或更高版本。如果 `python` 命令不可用，可安装 Python 并在安装时勾选“Add Python to PATH”。启动脚本也会尝试使用 Windows Python Launcher 的 `py -3.11.5`。

## 二、安装与启动

### 推荐方式：双击启动

1. 解压项目文件夹，确认最外层目录中能看到 `start.bat`、`main.py` 和 `requirements.txt`。
2. 双击 `start.bat`。
3. 第一次启动会在项目目录创建 `.venv` 虚拟环境，并安装 `requirements.txt` 中的依赖；之后启动会复用这个环境。
4. 等命令窗口显示本地访问地址后，在浏览器打开：<http://127.0.0.1:8000>。
5. 使用完成后，在命令窗口按 `Ctrl+C` 停止服务。

不要关闭正在运行服务的命令窗口。只允许本机访问，不要改成监听公网地址或局域网地址。

### 手动启动

在项目目录打开命令提示符或 PowerShell，依次运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

然后浏览器访问 <http://127.0.0.1:8000>。正式使用时不要添加 `--reload`，也不要用多个 Uvicorn worker 启动；本地发送队列按单进程后台线程设计。

### 如果启动失败

- 窗口提示找不到 Python：安装 Python 3.11+，重新打开命令窗口，再确认 `python --version` 可用。
- 依赖安装失败：确认网络可以访问 Python 软件包源，然后再次运行 `start.bat`。
- 提示 8000 端口占用：关闭另一个正在运行的本项目窗口，或结束占用 8000 端口的服务后重试。
- 修改 Python 代码或数据库结构后：先在运行窗口按 `Ctrl+C` 停止，再重新启动 `start.bat`。

## 三、第一次使用

1. 首页点击“准备演示数据”，创建演示收件人、模板和一条退订抑制记录。
2. 到“收件人”页面查看演示数据，或导入自己的 CSV。
3. 到“邮件模板”查看或维护模板。
4. 到“SMTP 设置”添加自己的 SMTP 账号，并用自己能访问的邮箱发送测试邮件。
5. 收到测试邮件后，再到“批量任务”创建真实任务。只发送给你有权联系的收件人。

演示邮箱使用保留的 `.invalid` 域名，不是真实邮箱，不能投递。演示数据适合查看页面、模板替换、抑制名单和队列状态；不要把演示收件人作为真实邮件测试地址。

## 四、收件人导入 CSV 格式

文件使用逗号分隔，首行必须是列名 `email,name,tags`。`email` 列必需；`name` 和 `tags` 可留空。支持 UTF-8 和 UTF-8 BOM 编码，中文姓名和标签可以直接填写。

```csv
email,name,tags
alice@example.com,张三,"客户,华东"
bob@example.com,李四,"体验用户,新品"
```

规则说明：

- 邮箱会去除首尾空格并转成小写后保存，大小写不同的同一邮箱会按重复处理。
- 邮箱格式必须类似 `name@example.com`；例如 `3202182590@qq,com` 不是合法格式。
- 同一邮箱只能有一条收件人记录。重复邮箱不会重复插入。
- 已启用抑制名单的邮箱会跳过导入。
- 导入结果会汇总新增、重复、无效和抑制数量。当前页面不提供逐行错误文件下载。
- 标签使用逗号分隔；如果 CSV 字段内部也含逗号，请像示例那样用双引号括起来。
- 姓名最多保存 200 个字符，标签最多保存 500 个字符。

项目自带示例文件：`sample_data/recipients.csv`。

## 五、SMTP 配置与测试

在“SMTP 设置”页面新增配置，填写：

1. 配置名称：自定义名称，便于区分账号。
2. SMTP 主机：以邮箱服务商当前官方说明为准。
3. 端口：常见加密方式为 465（SMTP over SSL）或 587（SMTP + STARTTLS）；实际端口必须以邮箱服务商和账号权限为准。
4. 账号：通常是完整邮箱地址。
5. 密码：可能需要 SMTP 授权码、应用密码或客户端安全密码，不一定是网页登录密码。
6. 发件人邮箱：填写该 SMTP 账号允许使用的发件地址。
7. 选择 TLS 设置：本软件对 465 端口使用 SSL；587 端口使用 STARTTLS。

保存后可在 SMTP 配置行使用“测试”，输入自己能访问的测试邮箱。测试会真实连接 SMTP 并尝试发送邮件。看到“服务器已接受提交”后，还应去测试邮箱检查是否收到；软件不会保证最终送达。

### SMTP 查询链接

先提供两个常用官方入口，服务商可能调整设置页面或账号安全策略，使用时请以网页当前说明为准：

- [QQ 邮箱官方帮助中心](https://service.mail.qq.com/)：可在帮助中心查询 SMTP/客户端服务开启方法及授权码相关说明。
- [网易邮箱官方帮助中心：网易邮箱服务器参数](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac22b85ac2e7c90cd63)：查询网易邮箱服务器参数；[网易客户端授权码说明](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac286624f309a1a7089)。

后续可在本节继续追加 Gmail、Outlook、阿里云企业邮等官方配置链接。不要把未核实的服务器地址、端口或授权码说明写成确定配置。

**当前限制：**此版本通过 SMTP 用户名和密码进行认证，不包含 OAuth2 登录流程。某些服务商或账户可能强制 OAuth2、关闭传统 SMTP 登录或要求额外开通权限；即使服务器地址正确，也可能无法通过本软件认证。遇到这种情况请先查看对应邮箱官方说明。本机测试 SMTP 尚不能替代服务商的账户授权。

## 六、模板与变量

模板可设置名称、主题、HTML 正文和纯文本正文。使用以下变量：

```text
{{name}}
{{email}}
{{tags}}
```

模板示例：

```text
主题：{{name}}，你好
正文：你好，{{name}}。你的邮箱是 {{email}}，标签为 {{tags}}。
```

HTML 变量值会进行自动转义；模板不执行任意 Python 代码。变量缺失会导致相应批量邮件失败。HTML 和纯文本内容都会发出。单发邮件页面使用你在单发页面填写的正文，不会自动套用模板。

模板删除规则：没有任务引用的模板可以物理删除；被任务引用的模板会从普通模板列表隐藏，但会保留用于任务历史。模板页勾选“显示已删除模板”可以查看并恢复。

## 七、批量任务与抑制名单

创建任务时选择任务名称、未删除的模板和启用中的 SMTP 配置，可填写标签筛选、每封邮件的间隔秒数和本机计划时间。当前批量任务针对符合条件的全部启用收件人；标签为空时不按标签筛选。

- 队列持久化在 SQLite；应用使用一个后台线程处理任务。
- 任务可暂停、恢复、取消；已结束任务可归档和取消归档。
- 收件人已停用或命中启用中的抑制记录时，队列会跳过该收件人。
- 发送状态包含待发送、发送中、已提交、失败、取消和结果待确认等状态。
- 发送中程序退出或连接结果不确定时，记录进入“结果待确认”，不会为了避免重复发送而自动重发。
- 计划时间使用运行电脑的本机时区；电脑关机期间任务不会运行。
- 目前按每封间隔限速，没有每批数量设置和自动重试管理页面。

抑制名单可添加、编辑和解除。解除抑制前，请确认已取得再次联系授权。SMTP 提交失败本身不等于硬退信；软件不会仅凭一般发送错误自动认定退信。

## 八、收件人、任务明细和发送日志的区别

这三类数据分开维护：

- **收件人**是当前联系人资料。停用会阻止其加入新的批量任务；删除会从普通收件人列表隐藏。
- **任务明细**是某次批量任务中每个收件人的快照，保存邮箱、姓名、状态、重试次数、错误结果和处理时间，位于 `campaign_details` 表。
- **发送日志**用于日志页面筛选、导出和清理。批量日志与单发日志分开清理。

清空批量日志会清理已结束项目的日志记录，待发送和发送中的队列项目会保留；任务详情快照不会随之删除。清空单发日志只清理单发事件。已被任务引用的收件人删除时会保留必要历史资料；收件人页面勾选“显示已删除”可查看并恢复。

应用升级时会为现存的发送队列补建任务明细。升级前已经被旧版本清日志操作物理删除的队列项目，数据库中已没有来源记录，无法自动重建；如需找回，只能从清理前备份恢复。

## 九、发送日志与导出

“发送日志”页面支持按邮箱搜索、按状态筛选和导出 CSV。批量日志和单发日志分别显示；CSV 使用 UTF-8 BOM，便于常见中文表格软件识别。清理操作会弹出页面中央的确认框。日志的“已提交”仍只表示 SMTP 接受提交，不代表送达。

## 十、数据库备份与升级

### 备份

1. 在运行服务的命令窗口按 `Ctrl+C` 停止软件。
2. 复制整个 `data` 文件夹，或至少备份 `data/mail_sender.db`。
3. 将备份放在项目目录以外的安全位置。

不要在服务运行时直接复制 SQLite 数据库文件作为唯一备份。更换电脑或解压新版本时，可在软件关闭后把数据库文件复制到新项目的 `data` 文件夹。

### 数据库升级

启动时程序会创建缺少的表，并对 SQLite 数据库执行少量增量字段升级，不会主动清空数据库。涉及任务明细的新版本会从当前仍保留的发送队列补建历史快照。升级前建议按上文先备份数据库。

## 十一、安全与使用边界
- 项目仅用于学习交流使用,请勿违法乱纪,出现任何问题由使用者自行承担。
- 默认只监听 `127.0.0.1`，不要把服务端口开放到公网或局域网。
- 当前没有登录、用户权限或 CSRF 防护，不适合部署为多人访问的公网网站。
- SMTP 密码/授权码目前保存在本机 SQLite 数据库中，已加密。保护 Windows 用户账户和项目目录，不要把项目目录或数据库上传到公开网盘、代码仓库或他人设备。
- 仅向已获得适当联系授权的收件人发送邮件，并遵守邮箱服务商发送频率、用途和反垃圾规则。
- 当前没有公网一键退订链接、List-Unsubscribe、真实退信接收、打开/点击追踪或 SPF/DKIM/DMARC 自动诊断功能。
- 软件没有真实 SMTP 凭据时无法代替用户验证真实发送；测试邮件请发送到自己控制的邮箱。

## 十二、环境变量

当前程序不会自动读取 `.env` 文件。出于安全考虑，GitHub 仓库不包含 `.env` 或 `.env.*` 文件；默认数据库路径是 `data/mail_sender.db`。需要改用其他路径时，可在启动 Uvicorn 前设置 `MAIL_DB_URL`，例如 PowerShell：

```powershell
$env:MAIL_DB_URL = "sqlite:///./data/mail_sender.db"
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

启动脚本默认切换到项目目录，因此相对数据库路径以项目目录为基准。
